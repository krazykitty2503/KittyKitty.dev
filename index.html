PRJ-05 // AI RESEARCH BUILDING

KittyLM

A from-scratch language-model research platform: byte-level BPE tokenizer, LLaMA-style dense baseline, resumable training, evaluation and inference. Built to understand and measure the whole stack, not to rival production assistants.

  • Python
  • PyTorch
  • ROCm
  • Tokenization
SYSTEM DETAILS
CURRENT STATE
Milestones A–D are implemented: tokenizer, model and attention benchmark, training with deterministic resume, and evaluation and generation (the README still lists D as in review). E–G have not started. Per the README, no model has been trained and no experiment results exist yet. The research configuration is around 17M parameters.
NEXT GATE
Milestone E (GPU smoke test), then the data pipeline and formal baseline experiments. Datasets and weights stay out of Git.

BASIS: public README + repo history · 2026-10-09 · SOURCE: public repo (Apache-2.0)

// 04 PRINCIPLES

How I build

Local-first & private

Prefer local inference and self-hosting where practical. Sensitive workloads stay on hardware I control.

Least-privilege agents

AI tools get explicit, scoped permissions. Consequential actions need a human to approve them.

Honest telemetry

Unknown is not healthy. Demos are labelled as demos. A status I can't verify isn't shown as good news.

Build, measure, understand

Learn by building real systems, record the evidence, and only then claim it works.
